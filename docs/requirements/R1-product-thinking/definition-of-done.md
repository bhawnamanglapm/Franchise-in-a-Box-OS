## 1c
- [ ] User stories and v1 scope are stated

- [ ] There are ≥ 6 edge cases
- [ ] There are ≥ 6 acceptance criteria, each testable with a number
- [ ] Post-launch success metrics have targets
- [ ] Meta platform facts are verified (A23)

## Overall
