# R2A: Onboarding Wizard: phases

| Phase | Goal | Entry | Activities | Exit | Time |
|---|---|---|---|---|---|
| **1. Brief** | Remove ambiguity before building | R5 input list known | Decide D-11; build brief, rubric, prompt pack, sample data | Every Must feature has a prompt; every rubric threshold is written down | 25 m |
| **2. Scaffold** | Correct shell and tokens | Brief | Prompt 1 (shared shell); check hex values | Dark theme matches the brief exactly | 10 m |
| **3. Core flow** | Steps 1–4 working end to end | Scaffold | Prompts 2–5 | Sample data flows through all 4 steps to a computed score | 70 m |
| **4. Complete** | Submit, persistence, states | Core flow | Prompts 6–7 | Test steps 1–5 pass locally | 20 m |
| **5. Stretch** | Depth if time remains | Test steps pass | Live LLM extraction | Stretch done or skipped | 0–30 m |
| **6. Ship** | Public and verified | Build complete | Deploy, 5-point test, one fix cycle | All 5 tests pass in incognito | 25 m |
| **7. Write-up** | Brief-required narrative | Shipped | From the build log only | F2A.W1–W5 complete | 15 m |
