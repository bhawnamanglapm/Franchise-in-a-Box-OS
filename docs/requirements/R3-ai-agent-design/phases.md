# R3: AI Agent Design: phases

| Phase | Goal | Entry | Activities | Exit | Time |
|---|---|---|---|---|---|
| **1. Triggers** | Measurable HITL rules | R1 states, A10, A22 | Conditions, signals, takeover views, keyword lists | 8 triggers, every one with a number or a defined signal | 20 m |
| **2. Prompt** | Production-grade prompt | Triggers final | Draft, then count, then trim | 150–250 words; all components F3.B1–B7 present | 15 m |
| **3. Model** | Defensible default | Verified vendor facts | Matrix, cost maths, choice | D-08 confirmed, with dated sources | 15 m |
| **4. Eval** | Real validation test | Triggers + prompt | Golden-set design, pass criteria, examples | Test can be run by someone else as written | 7 m |
| **5. Reconcile** | One source of truth | All of the above | Sync with R2B rules and R6A checkpoints | No drift between R2B, R3 and R6A | 3 m |
