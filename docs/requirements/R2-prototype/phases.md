| Phase | Goal | Entry | Activities | Exit | Time |
|---|---|---|---|---|---|
| **1. Brief** | Remove ambiguity before building | R1 1c + R3 final | Build brief, prompt pack, mock-data spec | Every Must feature has a prompt | Day 1 |
| **2. Scaffold** | Correct shell and tokens | Brief | Prompt 1; check the hex values | Dark theme matches the brief exactly | 15 m |
| **3. Core flow** | Inbox → thread → rules → state machine | Scaffold | Prompts 2–5 | Simulated message can flag, claim and return | 70 m |
| **4. Proof of "working"** | Reviewer-driven interaction | Core flow | Prompt 6: simulate box, computed badge, SLA | Test steps 2–4 pass | 15 m |
| **5. Polish / stretch** | Depth if time remains | 2 h freeze not reached | Prompt 7; optional LLM | Freeze at 2 h regardless | 10–30 m |
| **6. Ship** | Public and verified | Frozen scope | Deploy, 5-point test, one fix cycle | All 5 tests pass in incognito | 30 m |
| **7. Write-up** | Brief-required narrative | Shipped | From the build log only | F2.W1–W5 complete | 15 m |
