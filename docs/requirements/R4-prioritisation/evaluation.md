# R4: Prioritisation Under Constraint (Task 4): evaluation

## What the brief asks
"You can ship only 4 features in 3 weeks." Deliver:
- A ranked list (top 4) with a reason for each
- The remaining features grouped into **Month 2** and **Can be cut**
- **Scenario variation:** "One partner is a QSR focused on lead generation. Does your prioritisation change?"

## What reviewers will actually judge
- **Consistency with 1a.** A contradiction that isn't explained is a red flag.
- **Courage in "Can be cut".** Named features with a reason, not "nice-to-haves".
- **The QSR variation actually changes the order,** with reasoning. "No change" fails.

## Ambiguities and how we resolve them
| Ambiguity | Resolution | Assumption |
|---|---|---|
| Is a "feature" a module? | No. It's a sub-capability from the brief's module lists (about 25 candidates). | A8 |
| 3 weeks vs 30 days in 1a | Fewer than 30 days, so the thin Onboarding Portal drops from the 3-week set. A consultant enters brand data. State this explicitly. | A7, A21 |
| "Focused on lead generation" | The partner judges Scale100x on qualified leads delivered, not on closures | New: A24 |

## Draft position (to finalise in Phase 3)
**Top 4:**
1. WhatsApp AI Agent (qualification + FAQ, with lead intake)
2. HITL Takeover + unified timeline
3. Franchise Model Card + 3-year ROI as **approved facts** the agent can quote
4. Deal tracking & closure panel, which measures the revenue event

**QSR lead-gen variation:** the Meta Ads Agent (capture, CPL optimisation) and ad creatives move **into** the top 4. The deal closure panel and Model Card drop to Month 2. Lead scoring thresholds change for a lower-ticket, higher-volume funnel.

## Risks
| Risk | Mitigation |
|---|---|
| Dropping Onboarding looks like a contradiction with 1a | One explicit line: "3 weeks < 30 days. Onboarding runs manually for the 2 pilot brands." |
| Cutting things the founder likes | Each cut cites what replaces it (a manual or existing tool) and the condition for bringing it back |
| Looks contradictory: prototypes A and C build the donut, US benchmarks and AI insights that this ranking cuts | One explicit note: "The prototypes demo the module spec in the brief; this ranking decides production build order for 3 weeks." Each cut feature in a prototype is labelled v0 or illustrative. |
